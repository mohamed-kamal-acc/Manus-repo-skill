# 🚀 Enterprise Agent Skills Suite for Manus AI (52 Production Skills)

This repository contains a complete suite of **52 production-ready Agent Skills** following the open **Agent Skills Standard**, ready to be imported directly into **Manus AI** and compatible agentic environments.

---

## 📦 How to Import into Manus AI

1. Open **Manus AI** and navigate to the **Skills** tab in the sidebar.
2. Click **+ Add** in the top right corner.
3. Select **Import from GitHub**.
4. Paste the URL of this repository:
   ```text
   https://github.com/<your-username>/<your-repo-name>
   ```
5. Click **Import** — Manus will automatically detect, index, and register all 52 skills!
